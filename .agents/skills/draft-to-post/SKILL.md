# Draft → Blog Post 변환 (Codex 진입점)

Codex와 Claude는 같은 변환 절차와 말투 기준을 사용합니다. 작업 전에 두 문서를 읽습니다

1. [공통 말투·편집 기준](../../../docs/writing-voice.md) — 원본의 상황·의문·선택 이유 보존, 사실 창작 금지, 과장·직역·근거·반복·맥락 검토
2. [공동 변환 절차](../../../.claude/skills/draft-to-post/SKILL.md) — 트랙·카테고리, front matter, 시리즈, 다이어그램, 저장·검증 절차

문체·설명 분량은 공통 말투 기준을 따릅니다. 실제 시리즈의 slug·order·기준 버전은 해당 plan을 따릅니다
절차가 `.claude/` 아래 있어도 Codex에서 그대로 읽습니다. 경로를 `.Codex/`로 치환하지 않습니다
기존 글은 구조·기술 연결만 참고하고, 초반 글의 개인 서술을 살리되 근거 없는 비율이나 고정 템플릿까지 모방하지 않습니다

선택지 비교가 필요하면 [공동 선택지 가이드](../../../.claude/skills/draft-to-post/decision-tradeoff.md)를 읽습니다
원본의 사실·수치·기전·제약을 대조하고, lint와 공통 기준의 문맥 검토를 모두 수행합니다
