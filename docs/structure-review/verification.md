## 검증의 범위

원문 전개를 읽고 독자가 풀어야 하는 질문과 선행 개념을 기준으로 개선안을 작성했습니다
자동 검사는 그 판단을 담은 문서의 대응·근거 위치·누락·보존을 확인하는 용도입니다
자동 검사 통과가 읽기 쉬움이나 기술적 정확성을 증명하지는 않습니다

외부 글 6건은 설명을 배치하는 방식을 비교하는 자료로 사용했습니다
Kubernetes·라이브러리·커널에 관한 원문의 기술 주장 전체를 이번에 다시 검증한 것은 아닙니다
실제 학습자 대상의 읽기 시험, 후속 편집, 편집 뒤 독립 검수는 수행하지 않았습니다

빌드·앱 테스트는 실행 안 함
이번 변경은 게시 콘텐츠나 앱 코드에 들어가지 않는 검토 문서이며, 문서 검사만 실행했습니다
commit·push·배포는 실행하지 않았습니다
