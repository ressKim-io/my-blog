# Kubernetes 이론 글 구조 검토

Kubernetes 이론 71편을 처음 배우는 독자가 따라갈 설명 순서로 개선하기 위한 임시 작업 문서입니다
2026-10-25 최초 구조 검토에서 개선안을 기록했고, 같은 날 후속 사용자 요청으로 71편의 본문 편집과 독립 검토를 마쳤습니다
현재 진행 상태는 [실행 기록](execution/README.md)과 [글별 상태](execution/status.json)에 있으며, 아래 원문 기준과 `posts/` 검토서는 편집 전 기록입니다

## 읽는 순서

1. [공통 판단 기준](principles.md)에서 독자와 편집 원칙을 확인합니다
2. [외부 글 비교](references.md)에서 이번 검토의 출발점과 구체적인 전개 사례를 확인합니다
3. [시리즈별 연결](series-map.md)과 [편집 묶음](batches.md)을 참고해 [글별 작업 목록](index.md)에서 대상 검토서를 고릅니다
4. 대상 검토서와 원문을 함께 읽습니다. 다른 70편의 검토서를 한꺼번에 읽을 필요는 없습니다
5. 실제 수정 요청을 받은 다음 채팅에서 [후속 편집 지침](handoff.md)을 사용합니다

- 후속 본문 편집 71/71, 독립 검토 71/71, 미해결 편집 사항 0건: [실행 상태](execution/status.json), [검증 결과](execution/verification.md)
- 기준 commit: `d747a3b1767850670e50cc4cb58d357be019d282`
- 원문 파일별 SHA256과 시리즈 순서는 [manifest.json](manifest.json)에 있습니다
- 최초 검토서의 완료 표시는 구조 개선안 작성 완료를 뜻합니다. 후속 본문 편집·독립 검토 결과는 실행 기록으로 구분하며, 실제 학습자 대상의 학습 효과 검증은 수행하지 않았습니다
