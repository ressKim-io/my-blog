## 편집 전 전문 독해와 연결 계획

configmap-secret-delivery 전문·검토서 독해. 첫 비교표에서 생성 시 복사/롤아웃 비자동→AtomicWriter→subPath→재처리/immutable을 먼저 연결합니다. envFrom 우선순위·optional·키 규칙·EnvFiles는 후반 생성 시 조립 단위로 모읍니다. Secret 보안과 projected의 지원 조건은 유지하고 emptyDir/hostPath의 일반 설명은 독립 보충절로 구분합니다

## 실제 변경


- 위 계획대로 생성 조립의 세부를 갱신 경로 뒤로 이동했습니다. 기본 비교표와 두 그림을 보존했습니다
- emptyDir/hostPath 설명은 projected의 하위 설명이 아닌 별도 절로 구분했습니다

## 미채택 제안과 이유

다른 볼륨 설명을 새 글로 분리하거나 삭제하지 않았습니다. 분리 게시가 허용된 작업이 아니며 기존 크기·권한·메모리 사용 조건을 유지해야 합니다

## 보존 대조와 기술 확인

- baseline 대비 front matter·fenced code·링크/그림·inline code 다중집합 보존 검사 실행 완료
- immutable 재생성·subPath 참조·AtomicWriter 일관성 한계·Secret 매체/권한·EnvFiles 조건 유지. 새 기술 검증은 실행하지 않았습니다
- build·런타임 테스트는 담당 제한으로 실행 안 함
- API 값부터 프로세스 재읽기까지의 단계와 subPath가 링크 전환을 따르지 않는 이유를 본문에서 확인했습니다
