### R1 — 기본 배치 완료 전 Score 구현으로 전환

- 방향: 초반에는 후보를 점수로 비교한다는 역할을 남기고 세부는 후보 탐색 심화로 이동
- 재검토: Filter/Score부터 assume까지, 실패 정리 뒤 후보 탐색·점수 구현·PreEnqueue까지 다시 읽었습니다. 세부가 후반의 `선택 점수의 비교와 정규화 구현`으로 이동했고 초기 흐름에는 0~100·가중치의 기본 비교만 남아 해결됐습니다
