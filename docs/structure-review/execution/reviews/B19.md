### R1 — 권장 / 해결

- 위치·인용: scale 절 첫 문장 `HPA는 Scales(ns).Update(...)를 사용하며 SSA Apply를 보내지 않습니다`
- 독자가 막히는 이유: 원문에서는 SSA의 필드 소유권·충돌 역할을 설명한 뒤 나온 문장이었지만 현재 정의는 긴 계산·안정화 뒤에 있습니다. 아직 뜻을 배우지 않은 요청 방식과 비교합니다
- 수정 방향: 여기서는 목표 replica를 일반 Update로 갱신한다는 역할을 설명하고 SSA 비교는 정의 옆에 두거나, 기존 후반 내용으로 SSA 역할을 첫 사용에 최소 보완합니다
- 처리: scale 앞부분은 일반 갱신 역할로 설명하고 SSA 대비는 기존 정의 뒤로 옮겼습니다. 지표 조회→scale 역할→ReplicaSet 배분, 추천 이력→SSA 정의→실제 Update→managedFields 변환의 앞뒤를 재독해 해결로 판정했습니다. 최종 SHA 확인 및 재실행 lint error 0·장문 warn 1입니다
