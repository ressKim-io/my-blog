시작일: 2026-10-24
상태: 30편 편집·독립 검수·렌더링·전체 빌드 확인 완료

사용자는 다음 API 글부터 약 30편을 3편씩 나눠 진행하고, 배치가 끝날 때마다 판단·보완한 뒤 추가 질문 없이 계속하도록 요청했습니다
이번 대상은 API 시리즈의 남은 22편과 노드 시리즈의 다음 8편입니다
이전 Batch 01의 6편은 다시 편집하지 않습니다

## 진행 원칙

- 편집 에이전트는 배치별 3편 안에서만 작업하고, 다른 에이전트가 원문과 수정본을 독립 검수합니다
- 원문 대비 조건·수치·근거·주체를 보존하며, 자연스러운 한국어·설명 순서·반복을 개선합니다
- 검수 의견을 반영하고 해당 부분을 재확인한 뒤 다음 배치를 시작합니다
- 배치별 MDX 렌더링으로 파손 여부를 확인하고 전체 작업 뒤 빌드를 실행합니다
- lint, 일괄 단어 치환, 문단 수 할당, 모든 제목을 질문형으로 만드는 작업은 하지 않습니다
- 새 기술 주장·실습 경험·버전 갱신·분류 변경·자산 변경·commit·push·배포는 범위 밖입니다
- 현재 작업 트리에 있던 코드 변경과 첫 6편 편집은 보존합니다
