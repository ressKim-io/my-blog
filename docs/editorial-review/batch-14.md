## 대상과 실제 교정

### `k8s-theory-node-swap.md`

추상적인 회계를 배치 계산으로 풀고 편집 지시처럼 남아 있던 문장을 동작 설명으로 바꿨습니다

- 원문: 로그 파일 이름은 실행 결과이면서 다음 실행 번호를 정하는 입력입니다
- 수정: 로그 파일 이름은 지난 실행의 기록이면서 다음 실행 번호를 정하는 입력입니다

### `k8s-theory-hpa-scale-subresource.md`

## 독립 검수와 보완

별도 reviewer가 전문 대조 후 두 곳을 지적했습니다. Guaranteed 문장의 메모리와 Pod 주어를 나누고, 로그 GC의 '최소 보존 시간·개수'를 '최소 보존 시간과 보존 개수 제한'으로 고쳤습니다. QoS 예외와 MaxPerPodContainerCount 앞뒤 문맥을 재확인했습니다. 필수 의미 보존 오류는 없었습니다
